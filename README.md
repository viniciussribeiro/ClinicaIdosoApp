# ClinicaIdosoApp
Projeto de Extensão UNIP: desenvolvimento de um aplicativo para monitoramento de medicamentos em idosos. A ferramenta visa garantir o cumprimento das prescrições médicas, enviando alertas de horários e dosagens para usuários e cuidadores, reduzindo riscos de esquecimento e promovendo autonomia, segurança e qualidade de vida na terceira idade.
